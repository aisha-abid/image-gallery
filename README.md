# 🌟 Interactive Image Gallery

This is a dynamic and responsive **Image Gallery Web App** built with **HTML**, **CSS**, and **Vanilla JavaScript**.

## ✨ Features

- 🖼️ **Image Filtering** – Filter images by category using interactive buttons.
- 🔍 **LightBox Preview** – Click on any image to view it in a lightBox with next/previous navigation.
- ❤️ **Favorite System** – Mark images as favorites using the heart icon. Favorites are saved using `localStorage`.
- 🔄 **Heart Sync** – Heart icons are synced between the card view and the lightBox preview.
- 📱 **Responsive Design** – Fully responsive layout with hamburger menu for smaller screens.
- 💾 **LocalStorage Support** – Favorite selections are saved and persisted across page reloads.

## 📚 Technologies Used

- HTML5  
- CSS3 (FlexBox, Responsive Design)  
- JavaScript (DOM Manipulation, Events, localStorage)
